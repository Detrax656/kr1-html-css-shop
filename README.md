# Накал: магазин дизайнерских ламп

«Накал» — многостраничный интернет-магазин дизайнерских ламп: настольные лампы, торшеры и подвесные светильники.
Сайт адаптивный, с тёмной и светлой темой, каталогом с фильтром и отдельной страницей каждого товара.

## Страницы

- `index.html` — главная: hero, преимущества, популярные товары, вопросы и ответы, доставка и гарантия, карта;
- `catalog.html` — каталог из 12 товаров с фильтром (тип, цена, наличие, скидка);
- `product.html?id=N` — страница товара: описание, комплектация, характеристики, отзывы, похожие товары;
- `order.html` — форма заявки;
- `contacts.html` — телефон, e-mail, адрес, график работы, как добраться, карта.

## Структура проекта

- `css/style.css` — внешний вид: переменные, цвета, шрифты, состояния, лампочка-выключатель;
- `css/responsive.css` — раскладка и адаптивность (Mobile First, медиазапросы `min-width`: 640, 768, 900, 1024, 1280 px);
- `js/data.js` — массив товаров;
- `js/main.js` — функции работы с товарами, карточки, фильтр каталога, страница товара, модальное окно и форма заявки;
- `js/theme.js` — лампочка-выключатель и переключение темы;
- `images/` — логотип, favicon, hero-изображения (mobile/tablet/desktop), фото товаров `lamp-01 … lamp-12` в размерах 480, 640 и 960 px;
- `lighthouse/` — отчёты проверки Lighthouse;
- `sitemap.xml` — карта сайта.

## Возможности

- **Темы оформления.** Тёмная по умолчанию, светлая через `data-theme="light"`. Переключается лампочкой на шнуре рядом с логотипом: нужно потянуть за лампочку (мышью или пальцем), она загорится и тема сменится. Работает и с клавиатуры (Tab, затем Enter или пробел). Выбор запоминается в `localStorage`; при `prefers-reduced-motion` анимации отключаются.
- **Каталог на JavaScript.** Карточки строятся из массива `products`. Фильтр работает по типу светильника, цене (с учётом скидки), наличию и скидке.
- **Страница товара.** Открывается по `product.html?id=N`, данные берутся из того же массива.
- **Функции товара:** `formatPrice`, `calculateDiscount`, `calculateFinalPrice`, `getProductStatus`, `getShortDescription`. Отчёт по товарам выводится в консоль браузера.
- **Форма заявки** с HTML-валидацией и сообщением об отправке; на главной открывается в модальном окне.
- **Яндекс Карты** на главной странице и странице контактов.

## Адаптивность и доступность

- изображения: `<picture>` для hero, `srcset`, `sizes`, `width`/`height`, `loading="lazy"` для карточек, у всех изображений есть `alt`;
- сетка карточек: 1 колонка, 2 от 640px, 3 от 1024px; фильтр каталога слева и `sticky` от 1024px;
- шапка закреплена (`sticky`) от 768px;
- форма: одна колонка на телефоне, две от 768px, поля не ниже 44px;
- таблицы в обёртке `.table-wrapper` с горизонтальной прокруткой;
- ARIA используется только там, где нужна: `aria-label` у навигации, `aria-current` у текущей страницы, `aria-labelledby` у окна и разделов, `role="status"` у сообщений;
- контраст текста не ниже 4.5:1 в обеих темах.

Проверенные ширины: 360, 430, 768, 1024 и 1440 px.

## Технологии

HTML, CSS (переменные, Flexbox, Grid, БЭМ), JavaScript без библиотек.
