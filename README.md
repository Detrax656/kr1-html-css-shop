# Накал: магазин дизайнерских ламп (учебный frontend-проект)

## Описание

Проект выполняется в рамках дисциплины "Фронтенд и бэкенд разработка".

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница товара с таблицей характеристик, отзывами и похожими товарами;
- `order.html` — страница заявки с формой;
- `contacts.html` — контактная информация;
- `css/style.css` — внешний вид: переменные, цвета, шрифты, состояния;
- `css/responsive.css` — раскладка и адаптивность (Mobile First, медиазапросы `min-width`);
- `lighthouse/` — отчёты Lighthouse (скриншоты проверки доступности);
- `js/main.js` — файл JavaScript;
- `images/` — изображения (заглушка товара и её варианты 480/640/960 px, hero-варианты для mobile/tablet/desktop);
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Дополнительные элементы

- `sitemap.xml` — простая карта сайта;
- Open Graph-теги — базовая разметка для отображения ссылок.

## Используемые технологии

- HTML;
- CSS;
- JavaScript;
- Flexbox и CSS Grid;
- БЭМ;
- Git;
- GitHub и GitHub Pages.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров;
- CSS Grid для карточки товара и блока отзывов.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `product-details` — подробная карточка товара;
- `product-table` — таблица характеристик;
- `reviews` и `review-card` — блок отзывов;
- `faq` — блок частых вопросов;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.

## Позиционирование

- `position: relative` у `.product-card` — точка отсчёта для бейджа;
- `position: absolute` у `.product-card__badge` — бейдж (Новинка, Хит, Скидка, Нет в наличии) в правом верхнем углу карточки;
- `position: absolute` у `.order-dialog__close` — крестик в углу модального окна;
- `position: fixed` у `.to-top` — кнопка «Наверх» закреплена в правом нижнем углу окна;
- `position: sticky` у `.catalog-filters` — фильтры остаются на экране при прокрутке каталога;
- `z-index` у `.to-top` и `.catalog-filters`.

## Практическая работа №12: адаптивная вёрстка

Выполнено:

- подход Mobile First: базовые стили рассчитаны на телефон, расширения добавляются через `@media (min-width: …)`;
- брейкпоинты: 640, 768, 900, 1024 и 1280 px;
- стили разделены: `style.css` отвечает за внешний вид, `responsive.css` за раскладку и адаптивность;
- шапка закреплена (`sticky`) только от 768px, на мобильных не закреплена; навигация в колонку на телефоне и в строку на планшете и desktop;
- hero: одна колонка на мобильных, две колонки от 900px, изображение через `<picture>` с тремя `source`;
- сетка карточек: 1 колонка, 2 колонки от 640px, 3 колонки от 1024px;
- каталог: фильтр над списком на мобильных, слева и `sticky` от 1024px;
- изображения карточек: `srcset`, `sizes`, `width`/`height`, `loading="lazy"`, `aspect-ratio` и `object-fit`;
- форма заявки: одна колонка на мобильных, две от 768px, поля высотой не менее 44px, в модальном окне одна колонка;
- таблица характеристик в обёртке `.table-wrapper` с горизонтальной прокруткой;
- кнопка «Наверх» не перекрывает контент: отступы 16px на телефоне и 32px от 768px;
- палитра подготовлена в CSS-переменных (тёмная тема по умолчанию, светлая через `data-theme="light"`);
- исправлены ошибки: сломанный `<img>` на `product.html`, падение `main.js` на страницах без формы, лишний отступ под закреплённой шапкой.

Проверенные ширины: 360px, 430px, 768px, 1024px, 1440px. Горизонтального скролла нет.
