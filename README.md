# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины "Фронтенд и бэкенд разработка".

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт модального окна и валидации формы;
- `.gitignore` — список файлов, исключенных из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;
- JavaScript;
- Flexbox и CSS Grid;
- БЭМ;
- Git;
- GitHub и GitHub Pages.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Flexbox и Grid

Flexbox:

- шапка сайта `.site-header__inner` — логотип слева, меню справа;
- список меню `.site-nav__list` — пункты в одну строку;
- подвал `.site-footer` — тексты в ряд;
- кнопки формы `.form-actions` — выравнивание вправо.

Grid:

- сетка карточек товаров `.product-list` со столбцами `repeat(auto-fit, minmax(240px, 1fr))`, карточки сами перестраиваются на узких экранах.

## БЭМ

Классы названы по схеме `блок__элемент--модификатор`.

Примеры:

- блок `product-card`, элементы `product-card__title`, `product-card__text`, `product-card__price`, `product-card__button`, `product-card__badge`;
- блок `site-header`, элементы `site-header__inner`, `site-header__logo`;
- блок `site-nav`, элементы `site-nav__list`, `site-nav__item`, `site-nav__link`;
- блок `form-field`, элементы `form-field__label`, `form-field__control`, `form-field__hint`, модификатор `form-field--checkbox`.

## Позиционирование

- `position: relative` у `.product-card` — точка отсчёта для бейджа;
- `position: absolute` у `.product-card__badge` — бейдж Новинка в правом верхнем углу карточки;
- `position: fixed` у `.to-top` — кнопка «Наверх» закреплена в правом нижнем углу окна.
